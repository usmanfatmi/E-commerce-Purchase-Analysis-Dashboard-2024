# E-commerce Purchase Analysis Dashboard 2024

## Project Overview

The **E-commerce Purchase Analysis Dashboard 2024** is an interactive Excel dashboard developed to analyze customer purchases, sales performance, payment methods, discounts, and category-wise business insights.

This project demonstrates Excel Dashboard Development, Power Query Data Cleaning, Pivot Tables, Pivot Charts, KPI Cards, Slicers, and SQL Analysis to transform raw e-commerce data into meaningful business insights.

---

## Objectives

- Analyze overall sales performance.
- Track category-wise sales and orders.
- Compare payment method performance.
- Monitor monthly sales trends.
- Analyze average discounts by product category.
- Build an interactive dashboard using slicers.

## Dataset Information

The dataset contains **3,660 purchase records** with the following fields:

- User ID
- Product ID
- Category
- Price
- Discount (%)
- Final Price
- Payment Method
- Purchase Date

## Key Insights

- Clothing generated the highest sales among all product categories.
- Home & Kitchen offered the highest average discount.
- Credit Card and UPI were among the most preferred payment methods.
- Monthly sales remained relatively stable with noticeable peaks during selected months.
- Interactive slicers allow users to analyze sales dynamically by Category, Payment Method, Quarter, and Month.
